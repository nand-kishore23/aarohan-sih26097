# SYNTHETIC SEED DATA

The MVP target is approximately 500 synthetic beneficiary profiles.

Do not generate them until the canonical pathway set and skill/competency model are locked.

Seed records must include:
- `origin = SYNTHETIC`
- generation version
- scenario ID
- district
- beneficiary profile fields
- skill observations
- interests
- training capacity
- opportunity signals where used.

All synthetic opportunity data must be visibly labelled in the application.
