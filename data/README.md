# DATA DIRECTORY

```text
raw/
  source-preserved records

normalized/
  canonical normalized records

seed/
  synthetic demonstration data
```

## Rules

- Raw source records are immutable after capture except through versioned replacement.
- Normalized records retain source references.
- Seed data is synthetic unless explicitly documented otherwise.
- Never put production personal data in this repository.
- Never treat synthetic opportunity signals as real-world employment indicators.
