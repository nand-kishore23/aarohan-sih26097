# RAW SOURCE RECORDS

Place source-preserved documents here when they are actually obtained.

Recommended naming:

```text
<authority>__<qp_code>__<record_variant>__<retrieved_date>.<ext>
```

Do not overwrite a source record. Add a new version when the source changes.

For the current audit, authoritative source references are recorded in:
- `docs/11_DATA_AUDIT.md`
- `data/normalized/qualification_catalogue.json`
